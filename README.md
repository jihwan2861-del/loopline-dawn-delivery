# 루프라인: 새벽 배송

설치나 빌드 도구 없이 브라우저에서 실행하는 2D 옥상 러너 게임입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 시작 화면이 나옵니다. 게임 데이터는 이 브라우저에 저장됩니다.

## 조작

- 지붕 위에서 클릭·탭 또는 `Space` / `↑`: 점프
- 공중에서 누르고 있기: 앞쪽 고정점에 와이어 연결
- 와이어 연결 중 버튼 놓기: 와이어 해제 및 추진
- `Esc` 또는 `P`: 일시정지
- 오른쪽 위 음표 버튼: 효과음 켜기/끄기

모바일에서는 가로 화면으로 플레이하는 것을 권장합니다.
